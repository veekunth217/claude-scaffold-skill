# Examples — what `/scaffold` actually generates

Real outputs from running `/scaffold` against common stacks. These are **committed for reference** so you know what to expect before running the wizard yourself.

| Example | Stack | Generated by |
|---------|-------|--------------|
| [fastapi-postgres/](fastapi-postgres/) | Python 3.12 + FastAPI + PostgreSQL + Docker | `/scaffold` → `/python` |
| [nextjs-tailwind/](nextjs-tailwind/) | Next.js 15 + TypeScript + Tailwind CSS + Vitest | `/scaffold` → `/nodejs` |

Each example contains the files `/scaffold` would write into your project root. Source code stubs are intentionally minimal — the value is in the **shape**: CLAUDE.md, `.vscode/`, `.gitignore`, scaffolded folder structure, and a starter README.

Use these as a sanity check before running the wizard, or to bootstrap a similar project manually.
