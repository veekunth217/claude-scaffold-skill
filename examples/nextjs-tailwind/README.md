# nextjs-tailwind

Next.js 15 with the App Router, TypeScript strict mode, Tailwind CSS 4, and Vitest.

## Quick start

```bash
nvm use         # picks up Node 20 from .nvmrc
npm install
npm run dev
```

App available at http://localhost:3000.
